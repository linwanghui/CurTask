# 强化路线（存档版本 9）

## 界面与规则

- 使用 `73_ZRSJZ_DLC/Sprites/强化弹窗1` 素材；正式预制体仍为 `73_ZRSJZ_DLC/Prefabs/Panel/强化界面.prefab`，UUID 不变。
- 50 级主路线，每级强化一个固定属性；按等级依次购买，未开放节点可点击预览。
- 每 5 级额外开放一个菱形特殊节点，独立付费、可稍后补领，不阻挡主路线；5/15/25/35/45 级增加大红掉落概率，10/20/30/40/50 级增加换弹速度。
- 右侧显示材料持有/需求、金币持有/需求、单次提升、累计效果及解锁前提；左侧展示新路线的八项累计加成。
- 新路线不依赖账号等级。材料数量、价格和加成统一在 `Scripts/ZRSJZ_EnhancementConfig.ts` 中配置，已发布的节点 ID 不要重排或复用。

## 玩家实际效果

| 属性 | 生效方式 | 当前满路线加成（包含全部特殊节点） |
| --- | --- | --- |
| 攻击 | 玩家枪械/近战最终伤害增加固定数值 | +100 |
| 生命 | 玩家初始化时增加生命上限 | +200 |
| 移速 | 玩家移动速度加成 | +10% |
| 防御 | 原有减伤后额外抵挡固定伤害；至少受到 1 点伤害 | +50 |
| 技能伤害 | 玩家激光/轰炸的技能伤害倍率 | +30% |
| 技能冷却 | 主动技能冷却时长乘以 1−加成 | −10% |
| 换弹速度 | 换弹时长除以 1＋加成，进度条同步变化 | +25% |
| 大红掉落概率 | 与爆率针相加后相对提高局内红色概率，归一化权重；不影响盲盒 | +10% |

以上为强化自身的数值，其他装备、宠物、收藏室和增强针仍按照原战斗公式组合。双人玩家共用账号强化，联机玩家分别使用各自本地存档加成。

## 旧版本兼容

- `ZRSJZ_GameData.Versions` 从 8 升至 9；新增 `EnhancementLevel` 和 `EnhancementSpecials`。
- 无版本及 v0–v8 有效存档通过既有逐级迁移流程进入 v9。原始 JSON 先备份到 `ZRSJZ_GameData_before_v9`。
- 旧靶场、研究所、健身等级分别限制在 0–5 后求和，折算成新路线等级（最多 15 级）。旧靶场优先使用 `FacilityLevel.靶场`，缺失时读取 `FiringRangeLevel`，避免重复计算。
- 达到的 5 级特殊节点一并赠送，不扣材料或金币。升级后的属性采用新路线配置，不保证与旧设施数值逐项相等。
- 旧字段保留但旧加成作废；旧接口的生命、移速转读新路线，旧攻击百分比返回 0，新攻击在玩家伤害入口添加固定数值。
- 迁移只在跨越 v8→v9 时执行。v9 重载不再折算或补发，不影响金币、仓库、物品和任务数据。
- 发布时主包脚本和 DLC 强化预制体需要一起更新，通过正常构建资源版本更新缓存；不要将新版脚本与旧强化预制体混用。

## 验证

- `_data/upgrade/test-enhancement.cjs`：内存存档测试，覆盖 60 个节点、全部材料、旧版迁移及备份、重复加载/购买、材料/金币不足、实际扣除、特殊节点补购、满级和八类加成。
- `_data/upgrade/check-types.cjs`：检查相关脚本及传递依赖。两游戏包无类型错误，公共项目仍有原有的 18 条类型诊断。
- `_data/upgrade/preview.cjs`：独立浏览器上下文中运行真实 Cocos 预览，验证实际按钮购买、材料显示、5 级特殊节点和滚动。使用测试数据，不修改日常浏览器的玩家存档。
- 预制体和脚本通过本地 Cocos MCP 的资源保存/创建接口导入；预制体校验通过。
