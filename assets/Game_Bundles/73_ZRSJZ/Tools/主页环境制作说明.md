## 局部光照 Shader（2026-09-14）

- 灯泡熄灯彩蛋：场景中灯泡下的 `灯泡点击区域` 为 32×46，跟随灯泡缩放。首次点击播放原生 Spine `off` 姿态（灯具本体保留，halo/core 透明），同时将 Shader 光照与压暗强度归零；后续点击无效。状态只在组件实例内保存，不涉及玩家存档。不做手动恢复；场景重新加载后由 Cocos 创建新实例并播放默认动画，单纯禁用再启用不会重置熄灯状态。
- 回归测试：`Tools/test_home_lamp_easter_egg.cjs.txt` 覆盖重复点击、持续熄灯、移除事件监听、重新启用仍熄灯、新实例默认值及场景引用；仍需游戏内点击验收。

- 背景 Sprite 绑定 `主页局部灯光.mtl` / `.effect`，不是全屏改色或红色遮罩。
- `ZRSJZ_HomeLampLight` 仅传递灯的实时位置和 halo 插槽亮度，不创建节点、不重设位置；随原 Spine 2.4 秒循环，暂停和时间倍率也保持同步。
- BG 上的参数：`radiusPixels = 4800`（背景设计像素半径，在 3200 基础上增加 50%）、`strength = 0.5`、`darkness = 0.07`。边缘平滑归零，范围外不受影响。
- 用背景亮度梯度估算表面起伏，结合距离衰减、漫反射和微弱高光模拟附近墙体/金属受光；没有真实深度/法线贴图，因此不是完整三维光照，不产生真实遮挡阴影。角色和 UI 不使用此材质。
- 光晕扩大为 140×180，灯芯发光贴片由 9×17 扩大为 36×72，使实亮区域接近灯罩大小；灯体大小不变。灯芯峰值改为 ff303099（透明度 60%，降低泛白过曝），不降低背景反射强度。保留用户压缩后的 128×128 贴图，对应修正 atlas 尺寸。
- 实际观感仍需在游戏主页验收；可优先调低/调高 strength，无需重新生成图片。
